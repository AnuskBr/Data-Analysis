## GoT Analysis
This project explores character deaths in Game of Thrones using statistical methods to identify patterns.

### Methods Used:
- Chi-Square Test – Relationship between gender and nobility
- ANOVA – Impact of book introduction on allegiances
- Pearson’s r – Correlation between book of death and gender
### Data & Analysis:
- Preprocessed dataset of character traits and deaths
- Visual and statistical analysis of survival patterns
### Results & Conclusions:
Findings reveal key survival trends and relationships between character attributes.
